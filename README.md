# 치이카와 온라인 전멸전 — Render 배포

아직 배포되지 않은 소스입니다. 실제 공개 주소와 방 코드는 배포 후 게임에서 발급됩니다.

## 배포 순서
1. GitHub에서 새 저장소를 만들고 이 압축파일 안의 `server.js`, `package.json`, `render.yaml`, `public` 폴더를 저장소 루트에 올립니다. `public/index.html` 경로를 유지하세요.
2. Render에 로그인 → New → Blueprint → 위 GitHub 저장소 연결 → render.yaml 확인 후 배포합니다.
3. 배포 완료 후 표시되는 HTTPS 주소로 게임을 엽니다. 다운로드한 HTML이 아니라 같은 Render 주소에 모두 접속해야 합니다.
4. 닉네임과 캐릭터 선택 → ‘방 만들기’ → 표시된 6자리 코드를 친구에게 전달합니다.
5. 친구는 같은 주소에서 코드를 입력해 ‘코드 입장’. 양 팀 최소 1명씩 배치하고 방장이 ‘온라인 시작’을 누릅니다.
6. PC는 라운드 시작 후 ‘온라인 계속하기’를 눌러 마우스를 고정합니다. 모바일은 터치 버튼으로 조작합니다.

Blueprint 이용이 어려우면 New → Web Service → 저장소 연결 → Node → Build `npm install` → Start `npm start` → Health Check `/health`로 설정합니다.

## 이번 온라인 베타 범위
- 최대 8명, 팀당 4명, 방 코드, 팀 선택, 3라운드 선승 전멸전.
- 서버가 체력·탄약·연사 간격·머리/몸 피해·라운드 승패를 관리합니다.
- 저격총 즉시 판정, 기관총도 온라인에서는 서버 수신 즉시 판정합니다. 기존 로컬의 0.05초 지연과 다릅니다.
- 온라인 AI, 거점/화물/데스매치 동기화, 궁극기/수동 회복은 미지원. 화면에 남아 있는 로컬 메뉴는 오프라인 연습용입니다.
- 기지 보호 및 회복 포함. 온라인 캐릭터/팀 변경은 대기실에서 팀 버튼으로 반영합니다.
- 실서비스 수준의 이동 검증·지연 보정·재접속·관전·랭킹·부정행위 방지는 미완성입니다. 이동은 클라이언트 좌표를 제한 검증하는 프로토타입입니다.
- 서버가 검사하는 엄폐물은 단순화한 상자/나무줄기/바위/기지벽입니다. 나뭇잎 등 시각 요소와 판정이 완전히 같지 않을 수 있습니다.
- 서버 재시작이나 배포 시 메모리의 방 정보가 사라집니다. 같은 방 참가자는 같은 서버 인스턴스가 필요하므로 한 인스턴스로 운영하세요.
- 무료 서비스의 유휴/재시작 정책과 비용은 배포 시 Render 화면에서 확인하세요. 방 코드는 보안 암호가 아닙니다.

## 검사 범위
자바스크립트 문법과 순수 판정 알고리즘만 검사했습니다. 이 환경에서 서버를 실행하거나 실제 Render 배포/기기간 온라인 대전을 시험하지 않았습니다. 배포 후 두 기기로 입장·피해·사망·라운드 전환을 검증하세요.
