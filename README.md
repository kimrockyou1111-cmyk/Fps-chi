# 통합 방 업데이트 — Render

이 ZIP의 server.js, index.html, package.json, render.yaml을 기존 GitHub 저장소 루트에 덮어쓰세요. public 폴더는 필요하지 않습니다. Render 자동 배포가 켜져 있으면 커밋 후 다시 배포됩니다. 기존 방은 초기화됩니다. 연결한 모든 사람이 배포가 끝난 뒤 새로고침해야 합니다.

1. 방 만들기 또는 코드 입장. 실제 유저가 팀의 빈 슬롯에 표시됩니다.
2. 방장만 각 팀의 캐릭터 선택 드롭다운과 ＋ 버튼으로 AI를 추가할 수 있습니다. AI 옆 ×로 제거합니다.
3. 방장이 픽 단계 시작 → 각 유저가 영웅 선택 → 캐릭터 선택 완료. 모두 완료하면 전투 시작.
4. 다음 라운드는 이전 픽 유지. 3라운드 선승 후 로비 복귀.
5. 모바일 저격총: 사격 버튼을 누르면 스코프, 누른 채 드래그 조준, 손을 떼면 한 발 발사. 취소 이벤트는 발사하지 않습니다. 기관총은 누르는 동안 연사.

오디오는 브라우저 정책상 화면을 한 번 터치해야 활성화됩니다. 기기 무음 모드/미디어 볼륨도 확인하세요.

온라인 베타는 전멸전만 지원합니다. AI와 유저가 같은 서버 체력/피해/승패 규칙을 사용합니다. AI 경로 탐색은 간단한 회피 방식이며 복잡한 건물 주변에 멈출 수 있습니다. 이 업데이트는 서버를 실행하거나 Render에 직접 배포하지 않았으며, 실제 다중 기기 연결/시각/음향 테스트가 필요합니다. 지연 보정, 정교한 안티치트, 재접속, 거점/화물 네트워크 동기화는 미구현입니다. 적 방향 표시는 가까운 적 방향의 추정치입니다. 온라인 스폰 보호와 회복 유지.

## 총기 구도 업데이트
사용자가 제공한 FPS 스크린샷을 참고해 오른쪽 아래 총몸과 손을 크게 배치하고 총열은 중앙을 향하도록 뷰모델 카메라를 조정했습니다. 창 비율에 따른 왜곡을 줄이도록 뷰모델 렌더링 비율을 동기화했습니다. 실기기 시각 검증은 미실시입니다.
